# GhostNote: support and privacy

Public support site and privacy policy for **GhostNote: Video & Web Notes**, an iPad app for handwriting on top of lecture videos and websites.

- Support: https://dogukaneeser.github.io/ghostnote/ (Turkish: https://dogukaneeser.github.io/ghostnote/tr/)
- Privacy Policy: https://dogukaneeser.github.io/ghostnote/privacy.html (Turkish: https://dogukaneeser.github.io/ghostnote/tr/privacy.html)

**Need help or found a bug?** [Open an issue](https://github.com/dogukaneeser/ghostnote/issues/new). Issues are public, so please don't include personal information.

## About this repository

Plain static HTML and CSS served by GitHub Pages from the `main` branch. There is no JavaScript, no analytics, no cookies, and nothing is loaded from third parties.

- `index.html`, `privacy.html`: English pages. `tr/`: Turkish pages. `style.css`: shared styles.
- `demo/`: a fictional course page and slide images used only for App Store screenshots.
- To add a contact e-mail later, edit the commented block in the `#contact` section of `index.html` and `tr/index.html`. The privacy pages link there.
